# Channel artwork sources

These marks are used by the generated One Works distribution artwork.

- `telegram.svg`: Telegram logo geometry from Iconify `logos:telegram` (SVG Logos, CC0).
- `wechat.svg`: WeChat mark from Iconify `simple-icons:wechat` (Simple Icons, CC0).
- `wecom.svg`: WeCom mark derived from Iconify `tdesign:logo-wecom-filled` (TDesign Icons, MIT).
- `qq.svg`: QQ mark from Iconify `simple-icons:qq` (Simple Icons, CC0).
- `imessage.svg`: iMessage mark from Iconify `thesvg-color:imessage` (theSVG Color, MIT).
- Lark/Feishu reuses the repository's existing official login asset at
  `apps/relay-admin/src/login/assets/feishu-logo.png`.

Product names and trademarks remain the property of their respective owners.
