# One Works 0.1.0-beta.10

- Let explicitly watched local directory plugins run their client source in packaged and static hosts through a bounded compiler, while installed and marketplace packages continue to load their published production entries.
- Bundle the Browser, Chrome, and CUA drivers with the desktop app and expose their host-owned External Control settings without duplicating tab headings or descriptions.
- Add per-application CUA access rules keyed by macOS Bundle ID, with allow, ask-every-time, and deny policies plus session cursor preferences.
- Keep local production-identity desktop builds isolated from official immutable releases so rebuilt client, server, adapter, and plugin runtimes cannot silently reuse an older cache.
- Preserve the last valid PWA app shell when an update cannot fetch required HTML, JavaScript, or CSS assets instead of activating a partial cache.
- Harden managed marketplace metadata handling so private install paths and unvalidated metadata fields cannot leak into plugin presentation or diagnostics.
